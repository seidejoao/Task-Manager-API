# Task Manager API

A simple API for task management, built with Spring Boot and MongoDB.

## Overview

This API provides endpoints to create, read, update, and delete tasks. It is designed to be a foundation for a task management application, allowing users to efficiently organize their activities.

## Technologies Used

*   **Java 21**: Development platform.
*   **Spring Boot**: Framework for building Java applications.
*   **Spring Web MVC**: For creating RESTful endpoints.
*   **Spring Data MongoDB**: For interaction with the MongoDB database.
*   **MongoDB**: Document-oriented NoSQL database.
*   **Maven**: Dependency management and build tool.
*   **Lombok**: Library to reduce boilerplate code.
*   **Docker**: For containerization of the application and the database.

## Installation and Execution

There are two ways to run the application: using Docker or locally.

### Using Docker (Recommended)

The simplest method to run the application is by using Docker and Docker Compose. This will ensure that both the API and the MongoDB database are set up and running in isolated environments.

**Prerequisites:**

*   Docker
*   Docker Compose

**Steps:**

1.  Clone the repository:
    ```bash
    git clone <REPOSITORY_URL>
    cd task-manager-api
    ```

2.  Run Docker Compose:
    ```bash
    docker-compose up -d
    ```

The API will be available at `http://localhost:8080`.

### Running Locally

To run the application locally, you will need to have Java 21, Maven, and MongoDB installed and configured on your machine.

**Prerequisites:**

*   Java 21
*   Maven
*   MongoDB

**Steps:**

1.  Start the MongoDB service.

2.  Navigate to the project root directory and run the following command to build the application:
    ```bash
    mvn clean install
    ```

3.  Run the application:
    ```bash
    java -jar target/task-manager-0.0.1-SNAPSHOT.jar
    ```

The API will be available at `http://localhost:8080`.

## Task Data Model

The `Task` object has the following structure:

| Field       | Type          | Description                                   |
|-------------|---------------|---------------------------------------------|
| `id`        | `String`      | Unique task identifier (generated by MongoDB) |
| `title`     | `String`      | Task title                                  |
| `description` | `String`      | Detailed task description                   |
| `start`     | `LocalDateTime` | Task start date and time                    |
| `end`       | `LocalDateTime` | Task end date and time                      |
| `completed` | `boolean`     | Indicates whether the task is completed or not |

## API Endpoints

The base URL for all endpoints is `/task`.

| Method | Endpoint              | Description                               |
|--------|-----------------------|-------------------------------------------|
| `GET`  | `/all`                | Returns all tasks.                        |
| `GET`  | `/uncompleted`        | Returns all uncompleted tasks.            |
| `GET`  | `/completed`          | Returns all completed tasks.              |
| `POST` | `/add`                | Adds a new task.                          |
| `PUT`  | `/complete/{taskId}`  | Marks a task as completed.                |
| `PUT`  | `/edit`               | Edits an existing task.                   |
| `DELETE`| `/delete/{taskId}`    | Deletes a task by its ID.                 |

### Request Examples

#### Add a new task

**Request:**

`POST /task/add`

**Request Body:**

```json

    "title": "Implement authentication",
    "description": "Add user authentication with JWT",
    "start": "2024-07-26T10:00:00",
    "end": "2024-07-27T17:00:00"
}
```
